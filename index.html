MATRIX

An autonomous scanner that points eight specialist agents at a web application: SQL injection, XSS, CSRF, SSRF, command injection, authentication, API security, and repository secrets. Each agent works from a shared scan context, so evidence one turns up narrows the search for the others. Findings then reach an intelligence layer where a Llama 3.3 70B pass, confidence scoring, and an exploitability gate downgrade anything that cannot actually be exploited. What survives comes out as a CVSS v3.1 report with CWE mappings.

JITS

A deterministic pipeline that turns Indian court judgments into structured, queryable legal data. It normalises court names, extracts statutory sections across multiple acts, handles the IPC and CrPC transition to BNS and BNSS with date guardrails, and excludes self-citations before building a similarity graph. Nothing in it is a model guess; every output traces back to an explicit rule.

Sentinel formerly FraudGuard AI

Real-time fraud detection for banking and UPI transactions. A variational autoencoder catches novel anomalies while a deterministic rules layer handles the known patterns, which keeps rare but legitimate spending from tripping an alert. Built to catch structuring attacks that stay under per-transaction thresholds.

About

The interesting part is usually what gets thrown away.

I'm Jamil, a Computer Engineering student at A.P. Shah Institute of Technology. Every system I've built has run into the same problem: generating candidates is the easy half, and knowing which ones survive scrutiny is the other one. MATRIX raises potential vulnerabilities and an exploitability gate kills most of them.
